== Security Policy

=== Supported Versions

[cols=",",options="header",]
|===
|Version |Supported
|main |Yes
|===

=== Reporting a Vulnerability

Please report vulnerabilities through GitHub private vulnerability
reporting.

If private reporting is unavailable, contact: -
`+jonathan@metadatastician.art+`

Include: - affected component - impact summary - reproduction details -
any proof-of-concept material

=== Response Targets

* Initial acknowledgement: within 48 hours
* Triage decision: within 7 days
* Remediation target: severity dependent
